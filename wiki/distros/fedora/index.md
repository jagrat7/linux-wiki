# Fedora Family

Fedora-family systems include Fedora Workstation, Fedora Atomic desktops, RHEL-family derivatives, and related rpm-based systems.

## Distros

- Fedora Workstation
- Fedora KDE Plasma Desktop
- Fedora Silverblue
- Fedora Kinoite
- Red Hat Enterprise Linux
- Rocky Linux
- AlmaLinux

## Shared Notes

- Package tools: `dnf`, `rpm`
- Common package formats: `.rpm`, Flatpak
- Atomic variants use image-based updates and rollback-oriented workflows
