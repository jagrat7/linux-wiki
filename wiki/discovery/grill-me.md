# Grill Me Discovery Interview

This page defines the sharper discovery mode. The goal is to uncover what the user actually values, not just what they think they should want.

## Style

- Ask one focused question at a time
- Prefer concrete tradeoffs over abstract preference labels
- Reflect contradictions kindly
- Do not recommend until enough preferences are clear

## Useful Tensions

- Stable versus newest packages
- Easy defaults versus full control
- Beautiful desktop versus low maintenance
- Learning Linux versus getting work done
- Minimal system versus batteries included
- Immutable safety versus traditional flexibility

## Output

End with:

- A recommended distro or setup path
- Two alternatives
- One option to avoid for this user
- What to learn next
- What could make the recommendation change
